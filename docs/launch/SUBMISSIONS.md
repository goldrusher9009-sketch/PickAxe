# Launch kit

Status: hosted mode (`pickaxe-cli mcp --http`) is live at https://pickaxe.run/mcp (public, read-only, no sign-in) and a private token URL for personal use.

## Before any submission
1. Public repo at github.com/goldrusher9009-sketch/pickaxe with the code pushed.
2. A hosted, https endpoint run by you (restricted mode, token or OAuth). Do not expose a machine that holds private files.
3. A privacy policy page and a support contact.

## Directories
- Claude: submitted via claude.ai/directory/manage (Pickaxe Software Explorer), server https://pickaxe.run/mcp, no sign-in. Review takes a few weeks.
- ChatGPT: Developer mode custom connector works now; the app directory (platform.openai.com) needs identity verification, test credentials and a demo video from the account owner.
- Grok: custom MCP connector at grok.com/connectors. Grok Bot uses the Cursor plugin library: this repo has `.cursor-plugin/plugin.json` and `mcp.json`; submit the repo at cursor.com/marketplace/publish and cursor.directory.
