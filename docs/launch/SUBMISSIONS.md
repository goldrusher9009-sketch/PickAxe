# Launch kit

Status: hosted mode (`pickaxe-cli mcp --http`) exists and passes a manual curl test. It uses a bearer token. ChatGPT's connector flow and the public directories may require OAuth, which is not built.

## Before any submission
1. Public repo at github.com/goldrusher9009-sketch/pickaxe with the code pushed.
2. A hosted, https endpoint run by you (restricted mode, token or OAuth). Do not expose a machine that holds private files.
3. A privacy policy page and a support contact.

## Directories (each needs your own account)
- Claude: Anthropic connectors/MCP directory submission form.
- ChatGPT: Developer mode custom connector (works for you now); app directory submission needs OAuth.
- Grok: custom MCP connector in Grok settings.
