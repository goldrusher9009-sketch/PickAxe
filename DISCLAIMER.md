# Responsible use

Pickaxe studies software and helps you build your own version. Use it for software you own or are
authorized to examine: security research, interoperability, debugging, education, software
preservation, and recreating *behavior* you are allowed to recreate.

Do not use it to circumvent DRM, license checks or anti-cheat, to bypass authentication or access
controls, or to copy proprietary code or assets. Clean-room mode (the default) reads only what a
visitor or user can see, and is the safer choice. Deep mode reads program code and is for your
private, authorized use. You are responsible for complying with the law and the licenses and terms
of whatever you analyze.
